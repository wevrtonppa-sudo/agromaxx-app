AGROMAXX APP — VERSÃO WEB

Esta pasta é um site estático e pode ser publicado em qualquer hospedagem que aceite HTML/CSS/JS.

Arquivo principal:
index.html

Para testar:
1. Abra index.html no navegador.
2. O sistema funciona localmente e salva os dados no navegador.

Para publicar:
- envie index.html para sua hospedagem; ou
- arraste a pasta para um serviço de hospedagem estática.

IMPORTANTE:
Esta é a versão MVP. Para uso real por vários funcionários, a próxima etapa é adicionar backend, banco de dados, autenticação e permissões.
